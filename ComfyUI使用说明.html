01这套东西是什么

一个装在本机的二次元出图环境。ComfyUI 是引擎，上面叠了一层脚本，让你不用碰节点图也能出图。

分三层理解：

层是什么你需要碰吗
ComfyUI节点式出图引擎，管模型加载、采样、超分基本不用，只在改节点图时打开
工作流8 个预置的节点图（workflows_hq/*.json）偶尔，想加节点时
脚本层make.py 等，负责拼提示词、调参数、后处理日常就用这一层
一句话：日常双击 出图开关.bat 就能出图，不需要理解 ComfyUI 的节点。 节点图只在你想改结构（加一个 ControlNet、换采样器）时才需要看一眼。

03五分钟上手

从零到一张图。

  1. 双击 出图开关.bat。第一次会自动拉起 ComfyUI，等就绪（最多 180 秒）。
  2. 看面板上的 11 项，按编号翻转。常用的是 2 角色锁（锁住人物长相）和 3 超分（放大到 3072×5376）。
  3. 按 r 出图。等 40～70 秒，完成后自动打开输出目录。

产物在 output\make\<时间戳>\：

文件内容
01_shot.png原图（768×1344 或你选的尺寸）
02_upscaled.png4 倍超分（开了超分才有）
03_scene.png换背景后的合成图（开了换场景才有）

命令行等价写法

python make.py                          用 toggles.json 直接跑
python make.py -P jump                  指定跳跃骨架
python make.py -P off                   关骨架，随机姿势
python make.py --scene cherry --upscale 临时开场景和超分
python make.py --kao "(╥﹏╥)"            用颜文字指定表情
python make.py -p "white hair, blue eyes"  追加提示词
python make.py ... --save               把这次参数写回 toggles.json

04开关面板

11 项，翻完自动存盘。按 r 出图，q 退出。

键项目说明
1骨架off 不用 ControlNet，从 12 句姿势池随机抽一句塞提示词；auto 随机抽一个骨架预设；也可固定 reach_up / jump / stand / sit
2角色锁开 = 用 IP-Adapter 拿 refs/char 里的图锁长相
34x 超分出图后再放大，约 +20 秒，结果是 3072×5376
4换场景关 / 樱花庭院 / 废教堂 / 霓虹夜街。会把人物抠出来贴到新背景，带去色溢和接触阴影
5底模3dcg / soft / vivid / clear 四档，见下一节
6尺寸768×1344 / 832×1216 / 512×896 / 768×1216
7追加提示词接在默认主体描述后面，不覆盖
8动作包用 refs/*_web/_pack.json 里的骨架，覆盖第 1 项
9中文解析开 = 查询里的中文自动翻成 tag（词典映射，见第 6 节）
k颜文字写一个颜文字，展开成表情 tag 插在提示词最前面。? 看支持哪些
c换参考图从 refs/char 的 50 张里挑一张当角色锁参考

所有开关存在 toggles.json，面板每次退出自动写盘。也可以直接改这个文件。

05画风档

六个档，本质是「底模 + 采样参数」的组合，不额外占硬盘。

档名底模步数 / CFG默认尺寸适合
3dcgnova3dcg_v4028 / 5.0832×1216 手办质感、塑料高光。默认档
softwaiIllustrious_v17032 / 4.5832×1088 柔光半厚涂，皮肤通透
vividIllustrious-XL-v2.036 / 6.0832×1216 鲜艳赛璐璐，颜色饱和
clearhassakuXLIllustrious_v2230 / 4.5832×1088 清透亮，线条干净

06参考图与动作

四条通道各管一件事，别指望一条通道全包。

通道技术管什么不管什么
角色IP-Adapter（linear，0.80）长相、发色、配色姿势
服装IP-Adapter（linear，0.45）款式、颜色分布具体版型
质感IP-Adapter（style transfer，0.30）笔触、光影风格构图
动作ControlNet openpose（1.0 / 用到 0.75 步）身体姿势、朝向长相
为什么姿势只能靠 ControlNet： IP-Adapter 学的是「这张图长什么样」， 权重拉到 0.9 也只是让画面更接近参考图的构图，没法指定「左腿抬 30 度」。 姿势是空间约束，只有骨架管得了。

11故障速查

按症状找。每条都是实际踩过的。

症状原因处理
出图崩了 / 噪点 / 霓虹条纹 帧数低于 16（AnimateDiff） 已自动抬到 16 帧，若仍出现检查 style_lib.build()
报 Required input is missing: vae 工作流里 link id 被复用，或 inputs 用了旧 list 格式 跑 check_workflows.py，或 export_ui.py 重新转换
每次出图都一样 seed 或提示词写死在档里 加 --random，或面板不设 seed
出裸图 / 衣服不全 提示词只写了上衣，没写裙、袜、鞋 服装必须逐部位写清楚，光写 "white sailor uniform" 不够
喂了参考图但角色不像 参考图不是正方形，CLIP 中心裁切把脸裁掉了 multi_ref 会自动 square_crop；手动时先裁正方
骨架不跟 / 姿势不对 提示词和骨架互相打架（最常见，不是强度问题） 先查 standing、looking at viewer、plain wall background 这几个词
合成后一圈贴纸描边 IP-Adapter 收手太晚 ipa_end 从 0.65 降到 0.45
合成后有深色轮廓 源图投影残留（RGB 1,0,1 / alpha 254） 用拓扑法去投影，别按亮度阈值删（会吃掉线稿）
边缘留绿边 色度距离 0.071 高于阈值 0.040 提到 0.085
抠图抠出矩形 u2net 对二次元不灵 换 isnetis.onnx（model="isnet-anime"）
抠图变成整屏 mask 改动了 person_mask.alpha() 里的 min-max 归一化或等比缩放 那两行不能动，恢复原样
举手贴顶被裁 骨架贴画幅边缘，模型画得更长就出框 骨架 --zoom 0.86 留边，或加大画布
.bat 报 'xxx' is not recognized 文件编码不是 GBK+CRLF 重新用 GBK + CRLF 写，不要加 chcp 65001
读不到图 / cv2 报错 路径含中文 cv2.imread 读不了中文名，用 np.fromfile + imdecode
中文查询搜不到图 图站只认英文 tag 面板第 9 项打开，或手写英文
扒图一个 tag 写错就 0 条 图站是 AND 逻辑，无效词会让整条查询归零 已做两级容错（单查 + 贪心累加），若仍空就换词
等很久没反应 ComfyUI 没启动 make.py 会自动拉起并等 180 秒；仍不行手动双击启动 bat

12已知边界

这些不是没调好，是当前条件下做不到。省得反复试。

想做的事为什么不行
6 GB 显存训 SDXL LoRA SDXL LoRA 至少要 12 GB。6 GB 只能训 SD1.5 或 Textual Inversion
让模型重新打光（relight） 本地没有这个能力。人物是平光、场景是斜射光时，只能靠调色近似
颜文字当图形约束 模型把括号当耳机、弧线当机械面罩——它没有「颜文字=表情」的先验。只能走查表路线
精确控制魔法特效的形状 特效形状不可控，要做只能素材合成
喂图让画风越练越像 IP-Adapter 只在这一次生效，不会累积。要累积必须训 LoRA
半睁眼 / 眼部精细结构 眼周像素太少（latent 只有 5.6×2.6），重绘改不动，只能算法增强
国内直连扒优质图 danbooru / konachan / yande 全部超时，safebooru.com 被 Cloudflare 拦，只剩 safebooru.org 且质量参差
